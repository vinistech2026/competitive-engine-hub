# Competitive Engine Hub (CEH)

Autonomous Competitive Deconstruction, Market Feasibility & Clean-Room Replication Studio.

## Architecture & Principles
- **Niche-Independent:** Can inspect and map any web application (Spatial/GIS, Fintech, E-Commerce, SaaS).
- **Zero Cost ($0.00 / INR 0):** Uses public domain data, open-source libraries, and free hosting tiers (Vercel).
- **Hardware-Aware:** Built strictly for low-spec machines (Dell Latitude E6220, Intel HD 3000, 8 GB RAM) using 2D Canvas and pure DOM.
- **3-Tier Brevity:** Glance (30s) $\rightarrow$ Briefing (2m) $\rightarrow$ Appendix (Deep Schemas).
- **Graphify-Style Knowledge View:** Interactive node-graph visualization of software dependencies and open alternatives.

## Directory Layout
- `web-hub/`: Single-click dashboard with PWA support and Graphify visualization.
- `specs/`: Universal 10-dimension audit schemas.
